# DadoSorteio

App web simples do desafio de de Desenvolvimento Mobile:
- Sorteia um número de 1 a 6 ao clicar no botão.
- Troca a imagem do dado e a frase central.
- Permite inserir texto e concatenar na frase central.
- Inclui background personalizado e toast de resultado.

## Como rodar

Abra o `index.html` no navegador ou use um servidor local:

```bash
python -m http.server 8000
```
